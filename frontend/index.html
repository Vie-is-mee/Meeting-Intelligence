Xem hệ thống ghi nhận điều gì, thay đổi ra sao và dựa vào câu nói nào.

Kết quả LLM thật đã lưu · Không gọi API hoặc phân tích transcript mới. Giữ nguyên cả kết quả sai để đối chiếu.
Đang xem demo tĩnh: chọn một trong 8 tình huống để xem kết quả LLM đã lưu. Muốn phân tích transcript mới, chạy python -X utf8 web.py rồi mở http://127.0.0.1:8765.
Transcript hoặc tùy chọn đã thay đổi. Kết quả bên dưới thuộc lượt chạy trước; hãy phân tích lại để đối chiếu.
